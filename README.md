# 星曜對照簿

紫微斗數學習用的小網頁：把朋友的命盤存在一起，一次比較「同一顆星落在不同宮位」的情形，不用在 APP 裡一張張切換命盤。

## 功能

- **以星找宮**：選一顆星（十四主星、六煞、六吉、祿存天馬、生年四化、雜曜），列出每位朋友的這顆星在哪一宮、廟旺利陷、同宮有哪些星。
- **以宮看星**：選一個宮（例如夫妻宮），用表格比較每位朋友這一宮的主星、吉星、煞星、雜曜。
- **命盤**：傳統十二宮格式，含大限、干支、身宮、四化。點盤上任何一顆星，就跳到對照頁看所有人的這顆星。
- **學習筆記**：每個「星＋宮」組合都能寫筆記，例如「擎羊在田宅宮」。
- **匯出／匯入備份**：資料存在自己的瀏覽器，換電腦或換手機時用 JSON 檔搬家。

## 放到 GitHub Pages

1. 在 GitHub 建立新的 repository（例如 `ziwei-notebook`），設為 Public。
2. 上傳 `index.html` 和 `README.md`（Add file → Upload files）。
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
4. 等一兩分鐘，網址會是 `https://你的帳號.github.io/ziwei-notebook/`。

## 隱私

朋友的生日**只存在你自己瀏覽器的 localStorage**，不會上傳到 GitHub 或任何伺服器。其他人打開你的網址，看到的是空白的版本。
也因為這樣，清除瀏覽器資料會把名單清掉，記得定期「匯出備份」。

## 排盤來源

排盤使用開源函式庫 [iztro](https://github.com/SylarLong/iztro)（MIT）。不同門派在四化、閏月、子時的處理上有差異，若和文墨天機的結果不同，以你習慣的派別為準，並可在 iztro 的設定中調整。
