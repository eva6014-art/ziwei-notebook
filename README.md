# 星曜對照簿

紫微斗數學習用的網頁：把朋友的命盤放在一起，比較同一顆星落在不同宮位的情形，記錄真實事件來驗證，並整理成自己的筆記。

## 功能

- **對照**：以星找宮、以宮看星、以事件看；可切換本命盤、大限盤、流年盤。
- **命盤**：十二宮完整資訊、三方四正、飛化連線、忌追忌連鎖、大限／流年／流月疊盤。
- **事件紀錄**：記下朋友實際發生的事，自動算出當年的大限、流年與流年四化落點。
- **筆記**：依星曜或宮位整理所有筆記，可搜尋、可下載成 Markdown。
- **排盤設定**：四化版本、晚子時、年分界、閏月、安星法，可對齊文墨天機。
- **備份提醒**、**離線使用**、**加入手機主畫面**。

## 檔案

| 檔案 | 用途 |
|---|---|
| index.html | 網頁主體 |
| style.css | 外觀 |
| app.js | 程式 |
| iztro.min.js | 排盤函式庫（[iztro](https://github.com/SylarLong/iztro)，MIT） |
| sw.js | 離線快取 |
| manifest.webmanifest、icon-192.png、icon-512.png、apple-touch-icon.png | 加入主畫面用的設定與圖示 |

所有檔案都放在 repo 最上層，不要放進資料夾。

## 更新網站

1. repo 首頁按 **Add file → Upload files**。
2. 把所有檔案一起拖進去，按 **Commit changes**（同名檔案會覆蓋）。
3. 等一兩分鐘，重新整理網頁。

## 資料與備份

- 朋友、事件、筆記只存在**你自己的瀏覽器**，不會上傳到 GitHub。
- 電腦、手機、不同瀏覽器的資料各自獨立，要用「朋友 → 匯出備份／匯入備份」搬移。
- iPhone 從主畫面開啟的 App 和 Safari 的資料**也是分開的**：加入主畫面後，請在 Safari 匯出備份，再到主畫面的 App 匯入。
